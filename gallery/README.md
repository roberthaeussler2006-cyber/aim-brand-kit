# gallery

Approved AIM designs, kept as references for style and quality. Read only.
Each folder holds the source HTML plus the exported PNG/PDF.

- `2026-09-kickoff-pwc/`: Kickoff with PwC, September 2026. A3 poster (light) and four Instagram story variants (a glow, b editorial, c date, d minimal). Made before this kit existed: the HTML uses Helvetica, its own CSS and a mixed-case logo subline, which the brand rules have since replaced (Inter Tight/Geist, uppercase subline). Take the layouts as inspiration; build new designs from `templates/`.
