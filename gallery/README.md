# gallery

Approved AIM designs, kept as references for style and quality. Read only.
Each folder holds the source HTML plus the exported PNG/PDF.

- `2026-09-kickoff-pwc/`: Kickoff with PwC, September 2026. A3 poster (light) and four Instagram story variants (a glow, b editorial, c date, d minimal). Made before this kit existed, so the HTML uses Helvetica and its own CSS; take the layouts as inspiration, build new designs from `templates/`.
